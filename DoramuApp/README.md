# Doramu App

入力した文章や定型セリフを日本語音声で読み上げる、音声会話用の PWA です。
自分では話さず、アプリの音声を使って会話する — というコンセプトのアプリです。

元ネタ: ひよこプログラミング「Flutter で VIVANT のドラムが使うアプリを作成してみた」
（Flutter + `flutter_tts` で作られていたものを、このリポジトリの他アプリと同じ Web PWA として実装）

## 機能

- **自由入力の読み上げ** — テキストエリアに入力した文章を「発話」ボタンで読み上げ
- **定型セリフ** — 2列のセリフボタンをタップするとそのセリフを読み上げ（全11個）
- **停止 / クリア**
- **音声設定** — 声・話速・高さを画面から切り替え。設定は `localStorage` に保存されます
- **オフライン動作** — Service Worker でアセットをキャッシュ。読み上げは端末内の音声エンジンを使うのでネットワーク不要
- **ホーム画面に追加** — iOS / Android どちらもスタンドアロン表示

## 使い方

静的ファイルのみなので、任意の HTTP サーバで配信すれば動きます。

```sh
cd DoramuApp
python3 -m http.server 8000
# → http://localhost:8000
```

Service Worker とホーム画面追加を使うには `https://` または `localhost` が必要です。

## 音声設定

画面の「音声設定」から声・話速・高さを変更できます。イントネーションが気になる場合は
まずここで声を切り替えてください。

### 声の自動選択

`ja-JP` の先頭を無条件に選ぶと、iOS では標準品質の Kyoko が当たってしまいます。
iOS 16 以降の Premium / Enhanced（ニューラル音声）は `lang` が同じ `ja-JP` のまま
名前だけが違うため、`js/app.js` の `autoPickVoice()` で次の優先順位で選んでいます。

1. 名前に `Premium` / `プレミアム` を含む音声
2. 名前に `Enhanced` / `拡張` を含む音声
3. `Kyoko` / `Otoya` / `O-ren` / `Hattori`
4. その他の `ja-JP`

iPhone では「設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 日本語」から
高品質な音声をダウンロードできます。端末に入っていなければ選択肢に出てきません。

### 話速

元記事の Flutter 版は `flutter_tts` で `ja-JP` / pitch 1.0 / speechRate 0.55 を指定していました。
`flutter_tts` の速度は 0.0（最遅）〜1.0（最速）で、3.2.0 以降は Android も iOS / web と
同じ「0.5 = 標準」に揃えられています。つまり 0.55 は標準の約 1.1 倍にあたるため、
Web Speech API（`rate 1.0` が標準）では `1.1` を既定値にしています
（`js/app.js` の `DEFAULT_RATE`）。3.2.0 の新しいマッピングの正確な式は未確認なので、
1.1 は推定値です。

### そのほか

- 読み上げには端末の日本語音声が必要です。入っていない端末では英語音声で読まれる、
  あるいは無音になることがあります
- iOS Safari は `cancel()` の直後に `speak()` すると先頭が欠けたり無音になるため、
  発話中でなければ `cancel()` を呼ばず、ユーザー操作と同じ実行内で `speak()` しています
  （初回の `speak()` がジェスチャ内でないと iOS では音が出ません）

## セリフの編集

セリフは `js/data.js` の `SERIFS` 配列にあります。

| フィールド | 内容 |
| --- | --- |
| `label` | ボタンの表示 |
| `text` | セリフの正書き |
| `reading` | 読み上げ用のテキスト（省略時は `text` をそのまま読み上げ） |
| `status` | 出典の確度 |

`reading` は音声エンジンが漢字を読み間違える語だけに指定しています。
たとえば「別班」は「べつはん」と読まれてしまうため `べっぱん。` を、
「100,000ドル」は桁区切りのカンマで区切って読まれるため `10万ドル` を指定しています。

`status` フィールドは出典の確度を表します。

| status | 意味 |
| --- | --- |
| `exact` | 元記事から全文をそのまま復元できたセリフ |
| `guessed` | 元記事のPDFからテキストを抽出した際に漢字が欠落しており、かな部分の骨格から文脈で補完したセリフ |

`guessed` のものは各エントリのコメントに「元記事から確実に読み取れた範囲」を
書いてあるので、正しいセリフが分かれば `text` を書き換えてください。
現在 `exact` は「案内」「10万ドル」の2件、残り9件は `guessed` です。
